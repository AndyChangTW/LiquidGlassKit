# ClearPresetDemo

A minimal UIKit demo for comparing `LiquidGlassEffect.Style.regular` and `LiquidGlassEffect.Style.clear`.

Open `ClearPresetDemo.xcodeproj`, choose the `ClearPresetDemo` scheme, and run on an iOS device or simulator. On iOS 26+, the demo shows both native and forced fallback variants. On older iOS versions, native cards are replaced with availability placeholders.
